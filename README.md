#  BeeMonitor

> Sistema web desenvolvido para gerenciamento e monitoramento de informações relacionadas à atividade apícola.

## Sobre o projeto

O **BeeMonitor** é um projeto desenvolvido com Python e Flask como parte da minha experiência prática no desenvolvimento de aplicações web.

O objetivo do projeto é aplicar conceitos de desenvolvimento backend, persistência de dados e construção de interfaces web integradas a uma aplicação Flask.

## Principais objetivos

* Desenvolver uma aplicação web utilizando Flask
* Trabalhar com persistência de dados
* Criar uma estrutura organizada para aplicação backend
* Integrar frontend e backend
* Praticar operações com banco de dados
* Aplicar conceitos de desenvolvimento web

## Instalação

### 1. Clone o projeto

```bash
git clone https://github.com/vini-tsl/BeeMonitor.git
cd BeeMonitor
```

### 2. Crie um ambiente virtual

```bash
python -m venv venv
```

### 3. Ative o ambiente

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

### 4. Instale as dependências

```bash
pip install -r requirements.txt
```

### 5. Execute a aplicação

```bash
python app.py
```

Acesse:

```text
http://localhost:5000
```
